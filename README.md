# Student Grades Management System

A browser-based grade management application with real-time calculation, input validation, and dynamic table rendering, built with vanilla JavaScript, HTML, and Bootstrap.

Live Demo: https://mohamedkamel7413.github.io/Student-Grades-Management-System/

## Features

- Real-Time Calculation: grades and totals update instantly as data is entered
- Input Validation: prevents invalid or out-of-range grade entries
- Dynamic Table Rendering: student records are added, updated, and removed without a page reload
- Local Storage Persistence: all data is saved in the browser's Local Storage, so the app works with zero backend infrastructure
- Responsive, Accessible UI: built with Bootstrap for a clean experience across devices

## Tech Stack

- JavaScript (vanilla, ES6+)
- HTML5
- Bootstrap
- Browser Local Storage API

## Getting Started

No build step or server required, it's a fully static app.

git clone https://github.com/Mohamedkamel7413/Student-Grades-Management-System.git
cd Student-Grades-Management-System

Then simply open index.html in your browser, or serve it locally:

python -m http.server 8000

## Why This Project

Built to practice core JavaScript fundamentals, DOM manipulation, event handling, and client-side data persistence, without relying on a framework, while keeping the UI clean and usable with Bootstrap.
